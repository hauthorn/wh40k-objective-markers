# Warhammer 40k objective markers
Printable (on paper) objective markers including the scoring zone.

Objective markers are 4cm in diameter, the scoring zone is 4cm + 6 inches in diameter (thanks for mixing units, GW).

To use: 

1. Download/clone the repository
2. Open index.html in your browser
3. Print the page (A4 format)

Feel free to modify the markers as you see fit.
